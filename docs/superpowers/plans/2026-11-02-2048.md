# 2048 SOAP Implementation Plan

> Execution: superpowers:executing-plans，在用户指定当前空项目直接实施。

Goal: 可玩、可恢复且所有核心操作真实经过 SOAP 的课程项目。
Architecture: JSON → WSDL dynamic proxy → HTTP SOAP → SQLite；外部英文转换独立。
Tech Stack: Node 24 / node-soap / Express / SQLite / HTML CSS JS。
Spec: docs/design.md 与 docs/2048-soap-integration-spec.md。

## Global constraints
两个自建加一个外部；不伪造外呼；原目录不改；版本与持久幂等；中英文与移动端。

## Review focus
